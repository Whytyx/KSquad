# KSquad

Luxury UI mockup for a practical HR consultancy website (placeholder brand: Gayle People).

Built from website copy Version 11, with Insight colour accents used sparingly for the four service pillars:

- **Deep Gold** — Find the Right People
- **Cool Blue** — Get Your HR Foundation in Order
- **Fiery Red** — Deal With People Problems
- **Earth Green** — Ongoing People Support

Open `index.html` in a browser, or enable GitHub Pages on this repo to preview online.
